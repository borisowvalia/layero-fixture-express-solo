# layero-fixture-express-solo

Одно приложение: Express, без фронтенда.

**Проверяет** `T-20260826-3` — у бэкендов нет пресета, ветка Node.

Отличие от FastAPI: Node-бэкенду нужны ещё менеджер пакетов и версия Node,
и пресет обязан их спрашивать, а питоновский — нет.

Ожидание после правки: карточка «Express», поля установки, запуска
(умолчание `node index.js`), порта (умолчание 3000), менеджера и версии Node.

Последняя канарейка — `T-20260826-13`: рантайм-билдер исполняет план
источника, а не знает один github.com. Этот пуш проверяет, что GitHub-путь
от перевода на план не пострадал.
